Bahrain’s sea is rising and warming.Here’s what NASA satellites reveal about our coasts.

For over three decades (1993–2026), NASA radar altimeters and infrared radiometers have continuously measured the Arabian Gulf around Bahrain. Because Bahrain is a low-lying archipelago surrounded by shallow coral shoals and bays, ocean warming and rising water levels affect our shoreline faster than open-ocean averages suggest.

Why It Matters at Home

How a Warmer, Higher Sea Affects Daily Life in Bahrain

Even small changes in sea height and water temperature ripple into our streets, weather, fisheries, and utilities.

Slower Rain Drainage Along the Coast

Bahrain’s coastal storm drains rely on gravity to empty rainwater into the sea. When the sea sits about 14 cm higher (+4.2 mm/yr), especially during spring high tides and northwest Shamal setups, seawater pushes back into low-lying coastal outfalls in Manama, Muharraq, and Tubli.

Heat Traps in Shallow Bays & Coral Shoals

Shallow waters in Tubli Bay (1.4 m) and Fasht Al Adhm (1.8 m) absorb solar radiation much faster than the deep Gulf, pushing summer peaks past 35.4 °C (+2.2 °C warmer than open water) and stressing mangroves, seagrass meadows, and fish nurseries.

Harder Work for Water & Power Plants

Most of Bahrain’s drinking water comes from seawater desalination at Sitra and Al Dur, and coastal power stations use Gulf water for cooling. With 68 days/year exceeding 34.0 °C (+310% since the 1990s), intake cooling efficiency drops during peak summer demand.

Compound Shamal Winds & Spring Tides

When a strong northwest Shamal wind coincides with an astronomical spring high tide and our higher sea-level baseline, water piles up against northern and eastern coasts—requiring higher seawall freeboard along reclaimed islands.

#!/usr/bin/env python3
"""
Download NASA satellite-altimetry sea level anomaly grids for a box around Bahrain and write a
monthly CSV that bahrain_trend.py can read (use:  python bahrain_trend.py out.csv --preset sealevel).

Runs on YOUR machine or Google Colab (internet + a free NASA Earthdata account needed):

    pip install earthaccess xarray netCDF4 h5netcdf numpy pandas
    python fetch_sea_level_bahrain.py                     # NASA-SSH simple grid, 1992 -> present (default)
    python fetch_sea_level_bahrain.py --product measures  # MEaSUREs 1/6 deg grid, 1992 -> Dec 2022 (cross-check)

Products (both are SEA LEVEL ANOMALY relative to a long-term mean; they are NOT absolute heights):
  simple   NASA_SSH_REF_SIMPLE_GRID_V1   0.5 deg, weekly, ongoing, variable 'ssha'. Coarse, with ~100 km smoothing.
  measures SEA_SURFACE_HEIGHT_ALT_GRIDS_L4_2SATS_5DAY_6THDEG_V_JPL2205
           1/6 deg, 5-day, ends 2022-12, variable 'SLA'. Finer, but a shorter, older record.

The Gulf is small and shallow and altimeters are weakest near coasts, so the script reports how many
valid ocean pixels each month had. Check that column before trusting a trend.
Never paste your Earthdata password into a chat or a script; earthaccess asks for it securely.
"""
import argparse, datetime as dt, os, sys, tempfile
import numpy as np
import pandas as pd
import xarray as xr

PRODUCTS = {
    "simple": dict(short_name="NASA_SSH_REF_SIMPLE_GRID_V1", var_candidates=("ssha",), min_grids=2),
    "measures": dict(short_name="SEA_SURFACE_HEIGHT_ALT_GRIDS_L4_2SATS_5DAY_6THDEG_V_JPL2205",
                     var_candidates=("sla", "ssha"), min_grids=3),
}
# Default box: Bahrain plus enough surrounding Gulf to cover several 0.5-degree cells (west, south, east, north)
DEFAULT_BOX = (49.0, 24.8, 52.0, 27.4)
BATCH = 30   # granules downloaded per batch


# ------------------------------------------------------------------ pure functions (unit-tested)
def _find(names, options):
    low = {n.lower(): n for n in names}
    for o in options:
        if o in low:
            return low[o]
    return None


def find_coords(ds):
    names = list(ds.coords) + list(ds.dims) + list(ds.data_vars)
    lat = _find(names, ("lat", "latitude"))
    lon = _find(names, ("lon", "longitude"))
    tim = _find(names, ("time",))
    if not (lat and lon):
        raise KeyError(f"Could not find lat/lon in {names}")
    return lat, lon, tim


def find_var(ds, candidates):
    for name in ds.data_vars:
        low = name.lower()
        if any(low == c for c in candidates) and "err" not in low:
            return name
    raise KeyError(f"No sea level variable among {candidates}. Variables: {list(ds.data_vars)}")


def to_timestamp(value, units=None):
    """datetime64 -> Timestamp; undecoded numbers use a CF 'seconds/days/hours since DATE' units string."""
    if isinstance(value, (np.datetime64, pd.Timestamp)) or hasattr(value, "isoformat"):
        return pd.Timestamp(value)
    if not units or " since " not in units:
        raise ValueError(f"Cannot interpret time value {value!r} with units {units!r}")
    unit, origin = units.split(" since ", 1)
    unit = unit.strip().lower().rstrip("s")
    scale = {"second": 1, "minute": 60, "hour": 3600, "day": 86400}.get(unit)
    if scale is None:
        raise ValueError(f"Unsupported time unit {unit!r}")
    return pd.Timestamp(origin.strip()) + pd.Timedelta(seconds=float(value) * scale)


def reduce_dataset(ds, box, candidates):
    """Cos-latitude-weighted mean of the sea level anomaly inside the box, in mm.
    Returns (mean_mm, n_valid_pixels, n_pixels, timestamp)."""
    w, s, e, n = box
    latn, lonn, timn = find_coords(ds)
    var = find_var(ds, candidates)
    da = ds[var]
    if timn and timn in da.dims:
        da = da.isel({timn: 0})
    lon = ds[lonn]
    if float(lon.max()) > 180:           # grid uses 0..360, convert box
        w, e = w % 360, e % 360
    da = da.sortby(latn).sortby(lonn)
    da = da.sel({latn: slice(s, n), lonn: slice(w, e)}).load()
    if da.size == 0:
        raise ValueError("Box selected zero pixels; check the box and the grid's lat/lon.")
    # time
    ts = None
    if timn:
        t = ds[timn].values.ravel()[0]
        ts = to_timestamp(t, ds[timn].attrs.get("units") or ds[timn].encoding.get("units"))
    valid = da.notnull()
    nv = int(valid.sum())
    if nv == 0:
        return np.nan, 0, int(da.size), ts
    weights = np.cos(np.deg2rad(da[latn])).broadcast_like(da)
    mean_m = float((da * weights).where(valid).sum() / weights.where(valid).sum())
    return mean_m * 1000.0, nv, int(da.size), ts


def monthly_from_rows(rows, min_grids):
    """rows: DataFrame(time, mm, n_valid, n_pix). Monthly mean; months with too few grids -> NaN."""
    df = rows.dropna(subset=["time"]).copy()
    df["month"] = df["time"].dt.to_period("M").dt.to_timestamp()
    g = df.groupby("month")
    out = pd.DataFrame({
        "ssha_mm": g["mm"].mean(),
        "n_grids": g["mm"].count(),
        "valid_pixels": g["n_valid"].mean().round(1),
        "box_pixels": g["n_pix"].mean().round(0),
    })
    out.loc[out["n_grids"] < min_grids, "ssha_mm"] = np.nan
    out = out.reset_index().rename(columns={"month": "time"})
    return out


# ------------------------------------------------------------------ main (needs NASA access)
def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--product", default="simple", choices=list(PRODUCTS))
    ap.add_argument("--box", nargs=4, type=float, metavar=("W", "S", "E", "N"), default=DEFAULT_BOX)
    ap.add_argument("--start", default="1992-10-01")
    ap.add_argument("--out", default=None)
    a = ap.parse_args()
    cfg = PRODUCTS[a.product]
    out = a.out or f"bahrain_sea_level_{a.product}_monthly.csv"
    raw_path = out.replace(".csv", "_raw_grids.csv")

    import earthaccess
    earthaccess.login()

    results = earthaccess.search_data(short_name=cfg["short_name"],
                                      temporal=(a.start, dt.date.today().isoformat()), count=-1)
    print(f"Found {len(results)} grids for {cfg['short_name']}.")
    if not results:
        sys.exit("No grids found. The collection name may have changed; search 'sea surface height' on "
                 "search.earthdata.nasa.gov and edit PRODUCTS at the top of this script.")

    def gname(r):
        links = r.data_links()
        return links[0].split("/")[-1] if links else str(id(r))

    # resume support: skip grids already processed
    done, rows = set(), []
    if os.path.exists(raw_path):
        prev = pd.read_csv(raw_path, parse_dates=["time"])
        rows = prev.to_dict("records")
        done = set(prev["name"])
        print(f"Resuming: {len(done)} grids already processed.")
    todo = [r for r in results if gname(r) not in done]

    for b0 in range(0, len(todo), BATCH):
        batch = todo[b0:b0 + BATCH]
        for attempt in range(3):
            try:
                with tempfile.TemporaryDirectory() as tmp:
                    paths = earthaccess.download(batch, tmp)
                    new = []
                    for p in paths:
                        with xr.open_dataset(str(p)) as ds:
                            mm, nv, npix, ts = reduce_dataset(ds, tuple(a.box), cfg["var_candidates"])
                        new.append(dict(name=os.path.basename(str(p)), time=ts, mm=mm, n_valid=nv, n_pix=npix))
                rows.extend(new)
                break
            except Exception as ex:
                print(f"  batch {b0 // BATCH + 1}: attempt {attempt + 1} failed: {str(ex)[:120]}")
        pd.DataFrame(rows).to_csv(raw_path, index=False)
        last = rows[-1] if rows else {}
        print(f"  {min(b0 + BATCH, len(todo))}/{len(todo)} grids  latest {str(last.get('time'))[:10]}  "
              f"valid pixels {last.get('n_valid')}/{last.get('n_pix')}")

    df = pd.DataFrame(rows)
    df["time"] = pd.to_datetime(df["time"])
    monthly = monthly_from_rows(df, cfg["min_grids"])
    monthly.to_csv(out, index=False)
    print(f"\nWrote {out}: {len(monthly)} months, {int(monthly['ssha_mm'].isna().sum())} missing.")
    if monthly["valid_pixels"].median() < 2:
        print("WARNING: fewer than 2 valid ocean pixels per grid on average. The box is mostly land/masked "
              "at this resolution; widen it with --box W S E N before trusting a trend.")
    print(f"Next:  python bahrain_trend.py {out} --preset sealevel")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""
Download NASA Aqua-MODIS monthly SST for a small box around Bahrain and write a CSV that
bahrain_sst_trend.py can read. Runs on YOUR machine or Google Colab (needs internet + a free
NASA Earthdata account: https://urs.earthdata.nasa.gov).

    pip install earthaccess xarray h5netcdf netCDF4 numpy pandas
    python fetch_modis_sst_bahrain.py                 # daytime SST
    python fetch_modis_sst_bahrain.py --night         # nighttime SST (cross-check)

Only the small Bahrain window is read from each global monthly file, but each file is still
opened remotely, so a full run (~280 months) takes a while. It saves progress as it goes.
Never paste your Earthdata password into a chat or a script; earthaccess asks for it securely.
"""
import argparse, datetime as dt, re, sys, tempfile
import numpy as np
import pandas as pd
import xarray as xr

WEST, SOUTH, EAST, NORTH = 49.5, 25.5, 51.0, 26.7   # Bahrain + nearby Gulf waters
MIN_VALID_FRACTION = 0.20   # months with fewer valid ocean pixels than this become NaN


def find_sst_var(ds):
    for name in ds.data_vars:
        low = name.lower()
        if "sst" in low and "qual" not in low:
            return name
    raise KeyError(f"No SST variable found. Variables: {list(ds.data_vars)}")


def reduce_dataset(ds, box=(WEST, SOUTH, EAST, NORTH)):
    """Area-average SST inside the box (cos-latitude weighted). Returns (mean, valid_fraction)."""
    w, s, e, n = box
    var = find_sst_var(ds)
    da = ds[var].sortby("lat").sortby("lon")
    da = da.sel(lat=slice(s, n), lon=slice(w, e)).load()
    if da.size == 0:
        raise ValueError("Box selected zero pixels; check lat/lon names and box.")
    valid = da.notnull()
    frac = float(valid.sum() / da.size)
    if frac == 0:
        return np.nan, 0.0
    weights = np.cos(np.deg2rad(da["lat"])).broadcast_like(da)
    mean = float((da * weights).where(valid).sum() / weights.where(valid).sum())
    return mean, frac


def get_month(earthaccess, r, force_download=False):
    """Read one monthly granule. Try streaming first; if the server can't be streamed
    ('Cannot seek streaming HTTP file'), download it to a temp folder, read it, delete it."""
    if not force_download:
        try:
            f = earthaccess.open([r])[0]
            with xr.open_dataset(f, engine="h5netcdf") as ds:
                return reduce_dataset(ds)
        except Exception as ex:
            print(f"  streaming failed ({str(ex)[:80]}); downloading this file instead")
    with tempfile.TemporaryDirectory() as tmp:
        paths = earthaccess.download([r], tmp)
        if not paths:
            raise RuntimeError("download returned no file")
        with xr.open_dataset(str(paths[0])) as ds:
            return reduce_dataset(ds)


def month_from_name(name):
    m = re.search(r"\.(\d{8})_(\d{8})\.", name)
    if not m:
        raise ValueError(f"Cannot read date from {name}")
    return pd.Timestamp(m.group(1)).to_period("M").to_timestamp()


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--night", action="store_true", help="use nighttime SST product")
    ap.add_argument("--res", default="4km", choices=["4km", "9km"])
    ap.add_argument("--download", action="store_true",
                    help="skip streaming; download each file (slower but most reliable)")
    ap.add_argument("--start", default="2002-07-01")
    ap.add_argument("--out", default=None)
    a = ap.parse_args()

    short = "MODISA_L3m_NSST" if a.night else "MODISA_L3m_SST"
    tag = "NSST" if a.night else "SST"
    out = a.out or f"bahrain_modis_{'night' if a.night else 'day'}_sst_monthly.csv"

    results = earthaccess.search_data(short_name=short, temporal=(a.start, dt.date.today().isoformat()),
                                      count=-1)
    keep = []
    for r in results:
        links = r.data_links()
        name = links[0].split("/")[-1] if links else ""
        if f".L3m.MO.{tag}." in name and f".{a.res}." in name:
            keep.append((name, r))
    print(f"Found {len(results)} granules for {short}; {len(keep)} are monthly {a.res}.")
    if not keep:
        sys.exit("No monthly granules matched. Print a few granule names and adjust the filter "
                 "in this script (the naming may have changed).")

    rows = []
    for i, (name, r) in enumerate(sorted(keep, key=lambda t: t[0])):
        mean, frac = np.nan, 0.0
        for attempt in range(3):
            try:
                mean, frac = get_month(earthaccess, r, a.download)
                break
            except Exception as ex:
                print(f"  retry {attempt + 1} for {name}: {ex}")
                mean, frac = np.nan, 0.0
        if frac < MIN_VALID_FRACTION:
            mean = np.nan
        rows.append((month_from_name(name), mean, frac))
        if i % 12 == 0:
            print(f"  {i + 1}/{len(keep)}  {rows[-1][0].date()}  sst={mean:.2f}  valid={frac:.0%}")
            pd.DataFrame(rows, columns=["time", "sst", "valid_fraction"]).to_csv(out, index=False)

    df = pd.DataFrame(rows, columns=["time", "sst", "valid_fraction"])
    df.to_csv(out, index=False)
    print(f"\nWrote {out}: {len(df)} months, {int(df['sst'].isna().sum())} missing.")
    print("Next: python bahrain_sst_trend.py", out)
